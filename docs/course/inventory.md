# CP-PAW hands-on course — exercise inventory

The course is *CP-PAW Hands-On Course on First-Principles Calculations — Tutorial*, Peter E.
Blöchl, Robert Schade and Michael ten Brink, Institute of Theoretical Physics, Clausthal
University of Technology, © 2000–2019-09-26, 163 pages. Two identical-dated copies are on this
machine (`~/cp-paw/docs/`, `~/Documents/`); a separate 131-page *Theory* volume is not the target.

**The document is not in this repository and must not be.** Its notice permits personal and
classroom copies only; copying otherwise needs the author's permission. The historical CP-PAW
project made the same call and gitignores it (`~/cp-paw/.gitignore:63`). So: no PDF, no OCR text,
no figures, no verbatim prose here. What this file records is *parameters* — cells, positions,
cutoffs, k-point meshes, occupations — and a description in our own words of what each exercise
asks for, each row citing the chapter it comes from so anyone with the document can follow along.
OCR working text stays under `.scratch/cppaw/tutorial/`, which is gitignored.

Every example in `examples/` is generated by **Atomscope's own** CP-PAW schema from those
parameters; the course's decks are read as a specification, never pasted. Where our deck differs
from the course's, the difference is recorded in the example's own notes.

Parameters were cross-checked against `~/cp-paw/backend/app/tutorial_examples.py` (the historical
project's catalogue of the same course, GPL-3.0, same author as this project). That catalogue adds
systems the course does not cover — indole, a CH₃ClI NEB, the si2 regression fixture — which are
not part of this inventory.

## Status legend

`DONE` the example runs end to end and its result is visualized · `RUNS` the calculation
completes but part of what the course shows is not yet visualized · `BLOCKED` needs a feature
we do not have · `TODO` not started.

## What the course needs that we do not have

Ordered by how many exercises each unblocks.

1. **A sweep/series runner** — 6.3.6, 6.3.7, 8.2, 8.3, 8.4, 8.5 (six exercises, the whole of
   chapter 8). One parameter varied over a list, N jobs, one plot of the result against it.
2. **COOP** — 3.5, 4.7.5. Another `!WEIGHT` kind in the `.dcntl` plus a plot that can show
   negative values.
3. **`!OCCUPATIONS!STATE`** — 7.3, and already named as remaining in ROADMAP Phase 4.
4. **Cell dynamics** — 6.3.5; also gives 6.3.7 a second route.
5. **Empty atoms** — 6.3.3.
6. **`paw_tra` mode extraction** — 5.10.
7. **Contour/slice plots** — 3.4, and a genuinely useful viewer feature beyond this course.

## Working notes

- Runs live under `.scratch/course-runs/<exercise-id>/`, never in the repository.
- `examples/` holds the Atomscope project files: inputs, and results small enough to commit
  (energies, final geometries, DOS and band series, a thinned trajectory). Volumetric grids are
  regenerated by running the example.
