# Avogadro 1.2.0 feature-parity matrix for Atomscope

## 1. Scope, evidence and verification status

This document inventories the user-facing features of **Avogadro 1.x (target 1.2.0, `Avogadro_VERSION_FULL` in the top-level `CMakeLists.txt`)** as a parity matrix for Atomscope, a modern reimplementation.

**Evidence sources (all read-only, local):**

- Primary: the Avogadro 1 source tree at `/media/pmk/SysEx/cs/paw/avogadro/avogadro-master`. All `Evidence` paths in the matrix are relative to that root; `file:NN` denotes line numbers found with `grep -n`. Key locations:
  - `libavogadro/src/tools/` (7 interactive tools + z-matrix), `libavogadro/src/engines/` (17 display engines and their `*settingswidget.ui`), `libavogadro/src/colors/` (7 color maps), `libavogadro/src/extensions/` (30+ extensions incl. `crystallography/`, `orca/`, `qtaim/`, `quantuminput/`, `spectra/`, `surfaces/`, `swcntbuilder/`, `symmetry/`, `python/`, `gl2ps/`, `shaders/`).
  - `avogadro/src/mainwindow.ui` / `mainwindow.cpp` (menus, actions, file filters, docks), `settingsdialog.ui`, `pluginsettings.ui`, `projecttreeeditor.ui`, `importdialog.ui`, `editcommands.cpp`.
  - Every `*.ui` dialog (user-visible option strings were extracted with `grep -oE '<string>...</string>'`), which is how option lists such as basis sets, functionals, label types and isovalue controls were obtained.
  - Data-model headers `libavogadro/src/{molecule,atom,bond,cube,mesh,meshgenerator,zmatrix,residue,protein,animation,camera,glwidget}.h`.
  - `fragments/` (382 CML), `crystals/` (507 CIF), `testfiles/` (file formats exercised by the test-suite), `COPYING` (GPL v2).
- Handbook: `doc/index.docbook` contains only *Introduction* and *Installation* chapters (verified with `grep '<title>'`); it carries no feature descriptions, so the source tree is the sole substantive evidence. The archived web manual was **not** consulted (no network access assumed).
- Open Babel supplies file I/O and force fields at runtime (`libavogadro/src/moleculefile.cpp` uses `OBConversion::FormatFromExt`; `forcefielddialog.cpp` uses `OBPlugin::ListAsVector("forcefields")`). Formats and force fields listed here are therefore those Avogadro 1 *exposes in its own UI*, not the full Open Babel catalogue.

**Live verification is BLOCKED on this machine.** The installed `/usr/bin/avogadro` is **Avogadro 2 (1.101.0)**, which is a different code base and is deliberately excluded from this matrix (it appears only in the *Notes* column as a comparison point). A VirtualBox image containing Avogadro exists at `/media/pmk/SysEx/VM/avogadro_paw`; running it for side-by-side behaviour checks is out of scope for now. Every row is therefore sourced from code reading, not from running the application; the *Expected behavior* column is the behaviour implied by the code and should be confirmed against the VM before it is used as an acceptance test.

**Conventions.** `Status` is one of `IMPLEMENTED` (Atomscope does this, with a test behind it), `PARTIAL` (part of the row is done and the row's note says which part is missing), `NOT STARTED`, or `BLOCKED` (something outside Atomscope prevents it). The current counts are in `docs/STATE.md`; §3 below is the matrix itself. `Importance` reflects how central the feature is to a molecular editor (CRITICAL / HIGH / MEDIUM / LOW). `Implementation component` is a *suggested* Atomscope module. IDs are stable and should be referenced from issues/tests.

Build-time conditionality worth knowing (from `libavogadro/src/extensions/CMakeLists.txt` and top-level `CMakeLists.txt`): the Symmetry extension needs `BUILD_SYMMETRY` (bundled libmsym); GLSL shaders need GLEW and `ENABLE_GLSL` (default OFF); Python plugins/terminal need `ENABLE_PYTHON` (default ON, boost.python, Python 2 era); the Wii extension needs cwiid; Record/Play Test needs `QTTESTING`.

## 4. Intentional modernizations

Features below exist in Avogadro 1 but rely on obsolete technology or services. They are listed so nothing disappears silently; each has a proposed modern equivalent. The matrix row IDs are given for traceability.

| Avogadro 1 feature (row) | Why it is obsolete | Proposed Atomscope equivalent |
|---|---|---|
| Wii remote tracking (`wiitrackextension.cpp`, AV-PLUG-010) | Depends on cwiid/Bluetooth Wiimote hardware, Linux-only, unmaintained | Drop. Generic 6-DoF input (SpaceMouse) or WebXR/VR view if head tracking is ever wanted. |
| VRML export (`vrmlextension.cpp`, AV-EXPORT-004) | VRML97 is a dead format; the dialog (mm/Angstrom scale, smallest sphere, thinnest cylinder) shows it was a 3D-printing exporter | Export STL / 3MF (printing) and glTF/GLB (web, AR) from the scene graph with the same size controls. |
| POV-Ray export + external `povray` run (AV-EXPORT-003) | External renderer, slow, aging | Keep `.pov` writer for parity; add in-app high-DPI/path-traced offscreen render (e.g. headless GPU render at N x resolution, ambient occlusion). |
| Trajectory video via POV-Ray + `mencoder` (`trajvideomaker.cpp`, AV-VIB-008) | mencoder is obsolete; pipeline needs two external tools | In-app frame capture piped to ffmpeg (MP4/WebM/GIF). |
| gl2ps vector export PDF/SVG/EPS (AV-EXPORT-002) | gl2ps captures the fixed-function GL feedback buffer; modern GL pipelines do not support it | Generate SVG/PDF directly from the scene graph (spheres/cylinders as 2D projections with depth sort), or via a headless vector backend. |
| GLSL shader dialog with shipped .vert/.frag/.params (AV-VIS-040) | GLSL 1.x era shaders, built only with GLEW/ENABLE_GLSL | Built-in material presets (Phong, Gooch/toon, X-ray, ambient occlusion) as renderer options; optional user shader hook only if a plugin API is provided. |
| Label rendering backend choice QPainter vs TextRenderer (AV-VIS-017) | Two legacy text paths for GL text | One SDF/texture-atlas text renderer; setting removed. |
| Quick Render toggle and Low/Medium/High quality slider (AV-VIS-031, AV-VIS-033) | Manual LOD controls for weak GPUs | Automatic level-of-detail and impostor rendering; keep a simple quality preference for huge systems. |
| Threaded OpenGL option (AV-UI-023) | Qt4-era workaround | Not applicable in a modern renderer. |
| Python 2 / boost.python plugin API, SIP bindings (AV-PLUG-004..009) | Python 2 is EOL; boost.python bindings are heavy | Python 3 core API (Atomscope itself likely Python-first); plugins as entry points; terminal via Jupyter/IPython console widget. |
| QtTesting record/play `.drawlog` (AV-PLUG-011) | Qt4 pqTestUtility | pytest-qt (or Playwright if web frontend) scripted UI tests; keep `testfiles/*.drawlog` as behaviour specs to translate. |
| Fetch by chemical name via legacy resolver (AV-FILE-014) and IUPAC name lookup in Molecule Properties (AV-ANAL-001) | Original web services (NIH CIR / ChemSpider era endpoints) unreliable or gone | PubChem PUG-REST for name to structure; offline: RDKit/OB name generation not available, so mark as network feature with clear failure. |
| Fetch from PDB via legacy URL (AV-FILE-013) | Endpoint moved to https://files.rcsb.org | RCSB REST download, also AlphaFold DB id support. |
| Open Babel force fields incl. Ghemical placeholder (AV-MM-002) | Ghemical FF is historical; OB list is runtime | Force-field abstraction with backends: Open Babel (MMFF94/UFF/GAFF as available), ASE calculators (xTB, MACE, ANI), OpenMM for biomolecules. |
| Open Babel MD at fixed 300/600/900 K in Auto-opt tool (AV-EDIT-031) | Crude MD | Interactive optimization thread with pluggable minimizer; MD via ASE/OpenMM with user-set temperature. |
| Compute... buttons that spawn local QM binaries (AV-QM-018) | Blocking process launch, hard-coded executables | Job-runner abstraction (local subprocess, ASE calculator, remote queue) with progress and result import via cclib. |
| ESP surface option that errors "not yet supported" (AV-SURF-002) | Half-implemented feature | Implement ESP from partial charges (fast) and from wavefunction (accurate) rather than reproduce the error. |
| Project Tree Editor for custom tree layouts (AV-UI-011) | Rarely used complexity | Fixed, well-designed structure tree; drop the editor unless users ask. |
| Update check against avogadro.cc (AV-UI-018) | Points at old site | Opt-in update check for Atomscope, or delegate to the package manager. |
| One molecule per main window, "Window" menu (AV-UI-003) | Qt4 multi-window pattern | Tabs per document plus optional detach, preserving multi-view of one molecule (AV-UI-004). |
| Bundled third-party code (spglib, libmsym, gl2ps, OpenQube, TubeGen, qtiocompressor) | Vendored copies | Use upstream packages (spglib, libmsym via Python, ASE for tubes/slabs, Python gzip). |
