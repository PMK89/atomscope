# Fragment library

CML fragments copied verbatim from the Avogadro 1 source tree
(`avogadro-master/fragments/`, 382 files in 28 category directories plus `water.cml`),
Avogadro project, GPL-2.0-or-later; see `LICENSE-avogadro.txt` (copy of `COPYING`).
Atomscope is GPL-3.0-or-later, which is compatible with "GPL-2.0 or later".

Provenance: a local checkout on an external drive (`.../cs/paw/avogadro/avogadro-master`), 2026-09-05.
The directory layout is preserved; `atomscope.build.fragments` indexes it at runtime
(category = directory name, name from the CML `<name>` element or the file stem).
